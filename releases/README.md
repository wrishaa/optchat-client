# OptChat installers

Choose the folder for your operating system:

- [Linux](linux/README.md): DEB for Ubuntu/Debian and RPM for Fedora, for Intel/AMD 64-bit and ARM64.
- [Windows](../shells/windows/README.md): [x64 installer](windows/x64/OptChat-0.1.0.4-windows-x64-Setup.exe)
  or [ARM64 installer](windows/arm64/OptChat-0.1.0.1-windows-arm64-Setup.exe).
- [Android](../shells/android/README.md): [ARM64 APK](android/OptChat-0.1.0-dev-arm64.apk).

Each installer has a SHA256 checksum and build information alongside it. These are development test builds;
their recorded source revisions may predate the current checkout. New builds initially go to the ignored
`dist-dev/` directory; selected installers are copied here for easy access from the repository.
